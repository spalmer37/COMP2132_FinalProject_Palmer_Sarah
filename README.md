Save the Little Tree

A Peanuts Christmas Hangman game developed for COMP 2132.

- Guess the hidden Christmas-themed word one letter at a time.
- Use the on-screen keyboard or type your guesses.
- Each incorrect guess causes the tree to lose an ornament.
- You have six incorrect guesses before the game ends.
- Guess the word correctly to save the little tree!
